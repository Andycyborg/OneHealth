# OneHealth

OneHealth is a digital healthcare management platform designed to connect citizens, doctors, hospitals, and healthcare administration through a centralized system.

## Features

- Citizen registration
- Unique OneHealth ID generation
- Doctor registration and profiles
- Patient search using OneHealth ID
- Medical record management
- Prescription management
- Appointment booking
- Citizen medical history
- AI-generated medical record summaries
- AI healthcare chatbot
- Government health information dashboard
- Hospital listing and discovery

## Technology Stack

- Python
- Django
- Django ORM
- SQLite for local development
- HTML
- CSS
- AI API
- Git & GitHub
